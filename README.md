# Au-delà de l’Histoire

Média indépendant consacré à l’histoire africaine et mondiale, aux archives, aux découvertes et aux enquêtes documentées.

## Première version
- Page d’accueil responsive
- Sept rubriques éditoriales
- Dossiers de démonstration avec fenêtre de lecture
- Recherche locale dans les articles
- Identité visuelle vert africain, or et noir

## Aperçu local
Ouvrir `index.html` dans un navigateur. Aucun outil de compilation n’est nécessaire pour cette première version.

## Publication GitHub Pages
Dans le dépôt : Settings → Pages → Deploy from a branch → main → /(root).

## À faire avant une mise en production
- Ajouter des références bibliographiques précises à chaque dossier.
- Mettre en place Supabase avec des règles de sécurité (RLS).
- Créer une authentification administrateur côté serveur.
- Remplacer les contenus de démonstration par des articles validés.
- Ajouter une politique de confidentialité et des mentions légales.

L’espace administrateur et la publication distante ne sont pas encore activés. Ne jamais stocker de mot de passe ou de clé secrète dans les fichiers publics.
